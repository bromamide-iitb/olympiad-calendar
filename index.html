    How to Host & Deploy This Website

    Free, fast hosting options for students & developers

    1-Click Source Code Download

    Download this entire web application as a single `index.html` file to host anywhere.

    1

    Netlify Drop (Easiest - 30 Seconds, No Code)

    1. Click the Download index.html button above.
    2. Go to app.netlify.com/drop in your browser.
    3. Drag and drop the downloaded file/folder directly onto the Netlify Drop webpage.
    4. Your site is instantly live with a free SSL custom netlify link!
    2

    GitHub Pages (Free Permanent Hosting)

    1. Create a new public repository on GitHub.com named olympiad-calendar.
    2. Upload your index.html file directly into the repository root.
    3. Navigate to Settings → Pages in your GitHub repo.
    4. Under Branch, select main or master branch and click Save.
    5. Your site will be published live at https://username.github.io/olympiad-calendar/ within 1 minute!
    3

    Vercel Deployment

    Import your GitHub repository into Vercel.com. Vercel automatically detects static HTML pages and deploys them with global CDN speed.
